## 6. STRICT LINK SAFETY & GOVERNANCE RULES

To safeguard Ekora Bazaar's organic search visibility from algorithmic and manual Google Search penalties:

1. **Zero Tolerance for Paid Link Schemes:** Never buy links, participate in link wheels/networks (PBNs), or engage in automated mass-submission directory blasts.
2. **Proper Link Attribution (`rel="sponsored"` / `rel="nofollow"`):** If Ekora engages in paid sponsorship of an event, craft exhibition, or influencer partnership, ensure links use `rel="sponsored"`.
3. **No Automated Comment / Forum Spam:** Never post unsolicited links on Reddit, Quora, or craft forums using automated scripts. Community participation must be organic, value-additive, and comply with platform rules.
4. **Anchor Text Diversity:** Natural editorial links use brand names ("Ekora Bazaar", "Ekora"), naked URLs (`https://www.ekorabazaar.in`), or contextual phrases ("fragrance calculator tool"). Avoid artificial exact-match keyword stuffing (e.g. "wholesale candle wax cheap India").
